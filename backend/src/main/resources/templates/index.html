Sistema de Gestión y Comercio Electrónico

Plataforma académica diseñada para demostrar el control de acceso basado en roles (RBAC), autenticación segura con BCrypt, sesiones con protección CSRF y renderizado dinámico con Thymeleaf.

🎓 Proyecto Académico - Frameworks Web

Este aplicativo implementa un modelo de seguridad multi-rol empresarial utilizando Spring Security 6 y PostgreSQL. Los roles disponibles en el sistema son:

CLIENTE (ROLE_CLIENTE) VENDEDOR (ROLE_VENDEDOR) ADMIN (ROLE_ADMIN - Acceso Total)
